# Pocket Expedition Media

Public screenshot assets for the [Pocket Expedition](https://thunderstore.io/c/peak/p/Sapphire009/PocketExpedition/) idle RPG mod for PEAK.

These images are used by the Thunderstore README to show the main menu, combat HUD, character, equipment, skills, pets, special dungeons, rebirth, growth, ranking, expedition upgrades, and settings screens.
